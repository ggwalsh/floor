# Floor

Sketch a floor. Drop a bed, a desk, a built-in. Walk the layout before the boxes.

Runs on [geoffwalsh.xyz](https://geoffwalsh.xyz/tools/floor).

Click a piece or a wall, then type the size — `5 ft, 2 inches`, `192 in`, or `157 cm`. Imperial and metric both work; 192 inches becomes 16' 0". Walls, doors, windows, room labels, and a furniture catalog — including custom shapes and wall-mounted built-ins. Drag to move, drag handles to resize, R to rotate, arrows to nudge. Plans persist in the browser; export PNG or JSON.

```bash
npm install
npm run dev
```

Opens on http://localhost:5173
