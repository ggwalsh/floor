# Floor

Sketch a floor. Drop a bed, a desk, a built-in. Walk the layout before the boxes.

Same source [geoffwalsh.xyz](https://geoffwalsh.xyz/tools/floor) runs.

Walls, doors, windows, room labels, and a furniture catalog — including custom shapes and wall-mounted built-ins. Drag to move, R to rotate, arrows to nudge. Plans persist in the browser; export PNG or JSON.

```bash
npm install
npm run dev
```

Opens on http://localhost:5173
